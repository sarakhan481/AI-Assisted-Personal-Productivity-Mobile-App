# Productivity Buddy

## AI-Assisted Personal Productivity Mobile App

Productivity Buddy is a simple mobile-friendly productivity application that helps users manage their daily tasks, weekly tasks, and personal goals.

The application also allows users to track their productivity by showing completed tasks, pending tasks, and progress percentages.

The project was developed using HTML, CSS, and JavaScript. AI was used as a development assistant during different stages of the Software Development Life Cycle (SDLC).

## 2. Project Description

Productivity Buddy is designed to help users organize their daily activities and personal goals in one place.

The application allows users to add daily tasks, manage weekly tasks, create goals, mark completed work, and view their productivity progress.

The application is designed with a simple and mobile-friendly interface so that users can easily use it on a mobile-sized screen.

---

## 3. Main Features

The application provides the following features:

- Add daily tasks
- View daily tasks
- Mark daily tasks as completed
- Delete daily tasks
- Calculate total daily tasks
- Calculate completed daily tasks
- Calculate pending daily tasks
- Display daily completion percentage
- Add weekly tasks
- Complete weekly tasks
- Delete weekly tasks
- Create personal goals
- Mark goals as achieved
- Delete goals
- Calculate weekly task progress
- Calculate goal achievement percentage
- View overall productivity progress
- Navigate between Home, Tasks, Goals, and Progress
- Save tasks and goals using browser LocalStorage
- Reload saved data using the refresh button
- Mobile-friendly user interface
